身份验证

这不是破解，只是身份确认——就像原版 CICADA 使用 PGP 验证招募对象一样。 在游戏文件夹中运行下面的命令（PowerShell 或 Python 二选一），把输出粘贴回来。

PowerShell（Windows）：

powershell -ExecutionPolicy Bypass -File files/verify.ps1

Python：

python -c "import hashlib,getpass;print(hashlib.sha256((getpass.getuser()+'VERITAS-1145-SAPERE').encode('utf-8')).hexdigest())"
